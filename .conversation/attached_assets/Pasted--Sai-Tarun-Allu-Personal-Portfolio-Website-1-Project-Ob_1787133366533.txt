# Sai Tarun Allu — Personal Portfolio Website

## 1. Project Objective

Build a **premium, professional, modern developer portfolio website** for the domain:

**https://saitarunallu.com**

The website should position me clearly as a **Java Software Engineer / Java Developer** and present my technical skills, projects, education, professional experience, certifications, achievements, GitHub work, LinkedIn profile, and resume in a polished way.

This is a **personal professional portfolio**, not a generic template website. The final result should look credible for recruiters, hiring managers, and software companies.

The implementation must be designed for **static hosting and deployment on Netlify**.

---

## 2. Important Instruction — Plan the UI/UX Before Building

Do **not** immediately start coding individual sections.

First:

1. Analyze the content and determine the best information architecture.
2. Plan the complete page structure and navigation.
3. Define the visual hierarchy, spacing system, typography, responsive behavior, component structure, interactions, and mobile experience.
4. Decide how recruiters should be able to understand my profile within the first 10–20 seconds.
5. Create a consistent design system before implementing the page.
6. Avoid unnecessary visual effects, excessive animations, clutter, or gimmicky components.
7. Make every design decision serve either **professional credibility, readability, navigation, or conversion**.
8. Build the entire experience coherently from the beginning rather than implementing sections independently and redesigning them later.

The objective is to achieve a polished first implementation with **minimal or no rework**.

Before implementation, internally validate:

* Does the hero section immediately communicate who I am and what role I am targeting?
* Is the strongest project/work visible without excessive scrolling?
* Can a recruiter quickly access my resume?
* Are GitHub and LinkedIn easy to discover?
* Is the site readable on mobile?
* Does the visual design look like a professional software engineer's portfolio rather than a student template?
* Are sections ordered according to recruiter usefulness rather than simply copying the resume order?

---

* Excessive gradients
* Excessive glassmorphism

* Cartoonish illustrations
* Too many cards
* Excessive rounded containers
* Generic portfolio-template styling
* Fake statistics or fabricated achievements

The website should look credible when viewed by a **Java/Spring Boot recruiter or engineering hiring manager**.

A restrained accent color can be used for interactive elements and important highlights, while maintaining a professional neutral base.
